# Thought Tracks

A divided-attention train routing game inspired by Lumosity **Train of Thought**.

This game lives in the My Arkade monorepo.

**Source:** [github.com/arka5055/arka-arcade](https://github.com/arka5055/arka-arcade) (`thought-tracks/`)

## Play

**[https://amber-brick-glow-nova.grok.me/tracks/](https://amber-brick-glow-nova.grok.me/tracks/)**

- [Arcade home](https://amber-brick-glow-nova.grok.me/)
- [Thought Tracks](https://amber-brick-glow-nova.grok.me/tracks/)
- [Skyline Signal](https://amber-brick-glow-nova.grok.me/skyline/)

## Rules

- Each correctly routed train scores `100 × current level`.
- Wrong station is a miss. Misses do not subtract points.
- Stages 1–2 require a minimum number of correct trains. Stages 3–9 allow ≤3 misses.
- From stage 8, some trains and stations use two colors.

See [PROGRESSION.md](./PROGRESSION.md) for the Stage 1–9 map and skill ladder.
